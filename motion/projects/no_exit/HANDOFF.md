# No Exit Still Inside — 아스키 아트 뮤직비디오 인계 (2026-10-08)

## 의뢰
- 원장님 본인 노래 `song.mp3`(3:33, 약 94 BPM, 한 단어씩 끊어 부르는 차가운 곡) → **아스키 아트 모션그래픽 MV**.
- 원장님 선택: 컨셉 **"끝없는 글자 복도"(한 컷 원테이크)**, 가로 16:9.

## 디자인 체계
- 테마: "글자로 지은 콘크리트 복도 — 아무리 걸어도 같은 자리"
- 배경 `#0b0c0d`, 글자 회색(18단계), 강조 1색 = 형광등 초록빛 흰색 → light / exit / still / inside / opens, 천장 형광등, 복도 끝 빛, EXIT 표지에만.
- 글꼴: JetBrains Mono 800(화면 전체 글자 격자 192×60칸, 칸 10×18px), Pretendard ExtraBold(큰 단어 모양 마스크 — 화면엔 그 단어의 글자들로 채워 보임).
- 움직임: 앞으로 전진만. 단어는 멀리서 날아와 **부르는 순간 착지**(0.42초), 머물다 카메라를 지나쳐 사라짐.

## 장면 연출 (no_exit.html의 키프레임 배열)
| 배열 | 역할 |
|---|---|
| `SPEED` | 전진 속도(구간마다, 마지막 후렴이 가장 빠름) |
| `ROLL` | "time folds" 때마다 복도가 반 바퀴 접힘(72.4s, 129.7s, 171.7s), 간주 92–114s 천천히 한 바퀴 |
| `SPLITX/SPLITY` | 후렴2 = 복도 2개(133s~), 마지막 후렴 = 4개(182s~) |
| `SIGN` | EXIT 표지 — 늘 같은 거리(6.5)에 매달려 **아무리 가도 닿지 않음** |
| `ENDL` | 복도 끝의 빛 (light / ends / opens / stay 에 맞춰 커졌다 꺼졌다 다시 열림) |
| `CURSOR` | 시작·끝의 깜빡이는 커서 `___` (수미상관) |
| `LYR` | 단어별 시각 |

## ⚠ 유료 API 규칙 (2026-10-08 사고 후 원장님과 정함)
- **Gemini·ElevenLabs 등 유료 API는 원장님께 먼저 여쭙기 전엔 한 번도 호출하지 않는다.**
- v1 가사 측정에 Gemini를 반복 호출(성공 약 170건, 절반은 Pro 모델)하다 Google 프로젝트 월 한도(약 5만 원)에 걸림.
  그런데 Gemini의 시각 추정은 0.3~1.6초씩 틀려 쓸모가 거의 없었음 → 결과 없이 돈만 쓴 셈. 부정확하면 즉시 멈추고 무료 방법으로 바꿀 것.

## 가사 시각 측정 방법 (v2, 무료)
1. 목소리 분리: `motion/tools/separate_vocals.py` (UVR-MDX-NET-Voc_FT.onnx, GitHub 배포 모델, onnxruntime CPU, 3분 33초 곡에 약 6분).
2. 목소리 트랙 음량(10ms) + 소리 시작점(onset)을 구해, 단어가 조용함에서 새로 시작하는 지점을 그 단어 시작으로.
   1절처럼 단어가 떨어진 구간은 이 방법으로 정확. 노래가 이어지는 후렴은 목소리 파형 그림을 보며 손으로 정리(±0.2~0.3초 가능).
3. 164~170초는 목소리가 없음(v1은 여기에 잘못된 still inside가 있었음). 149·160초대 긴 허밍은 "…"로 표시.
4. 화면은 소리 시작 0.03초 전에 단어가 착지(`LEAD`), 날아오는 시간 0.25초(`ARRIVE`).
